Free Software Foundation Europe（FSFE）は、利用者がテクノロジーを自らコントロールできるよう支援する公益団体です。

ソフトウェアは、私たちの生活のあらゆる側面に深く関わっています。だからこそ、テクノロジーは私たちを制限するのではなく、私たちの力を高めるものであることが重要です。

自由ソフトウェアは、すべての人に、ソフトウェアを使用し、理解し、改変し、共有する権利を与えます。こうした権利は、表現の自由、報道の自由、プライバシーといった、その他の基本的な自由を支えることにもつながります。

FSFE は2001年、非営利・非政府組織およびネットワークとして設立されました。FSFE 自身も、共通の目標とビジョンを持つ人々による世界的なネットワークの一部です。

FSFE はヨーロッパ各地のメンバーによって支えられており、11か国に地域支部があります。FSFE の活動の中心となるのは、自由ソフトウェアを支える法的・政治的・社会的基盤を強固かつ安全に保ち、特定の利害に左右されないものとすることです。

https://www.fsfe.org

2017年、FSFE は、公費で開発されるソフトウェアについて自由ソフトウェア・ライセンスを標準とすることを目指し、「Public Money Public Code」イニシアチブを開始しました。

2017年秋に公開された公開書簡には、150を超える組織と19,000人を超える個人が署名しました。

このキャンペーンは、ライセンスの選択が持つ重要性への理解を広げるとともに、行政機関が自らのデジタルインフラを全面的に管理し、信頼できるシステムを構築できるよう支援しています。

https://www.publiccode.eu
