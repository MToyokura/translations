# オープン・レボリューション

## 著者

ルーファス・ポロック博士は、研究者、技術者、起業家である。彼は、グローバルなオープンデータ運動のパイオニアであり、各国政府、国際機関、産業界などにデジタルの世界でどのように成功を収めることができるかをアドバイスしている。35以上の国に存在するNGOであるOpen Knowledgeのファウンダーであり、人々と組織に情報へのアクセスを提供することで彼らが知見を生み、変革を先導していくことを後押ししている。以前、彼はケンブリッジ大学エマニュエル・カレッジの経済学ミードフェローであった。100万ドルを与えられるシャトルワース・フェローシップの受賞者であり、現在はアショカ・フェロー及びRSAフェローである。ケンブリッジ大学で経済学の博士号と数学のダブルファーストを取得。
